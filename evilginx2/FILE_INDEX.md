## 🔄 Workflow

```
User starts here ↓
      │
      v
1. run build_frontend.sh
      │ → npm install (frontend dependencies)
      │ → npm run build (builds React app)
      │ → generates frontend/dist/
      v
2. go build main.go
      │ → compiles Go backend
      │ → includes api_service.go & http_api.go
      v
3. ./evilginx2 -api -api-pwd "password"
      │ → starts CLI (normal terminal)
      │ → starts HTTP API (background)
      │ → serves static React frontend
      v
4. open http://localhost:8080
      │ → React frontend loads
      │ → login with password
      │ → access dashboard
      v
5. Use web UI or API
      │ → View/edit sessions
      │ → Manage phishlets
      │ → Execute commands
      │ → Monitor operations
      v
```

## 🚀 Getting Started

1. **Validate setup:**
   ```bash
   chmod +x validate.sh && ./validate.sh
   ```

2. **Build frontend:**
   ```bash
   chmod +x build_frontend.sh && ./build_frontend.sh
   ```

3. **Build backend:**
   ```bash
   go build -o evilginx2 main.go
   ```

4. **Run:**
   ```bash
   ./evilginx2 -api -api-pwd "your_password"
   ```

5. **Access:**
   ```
   http://localhost:8080
   ```
